# Анализ и ревью Java-проекта ПМ.02

## Что проверено
- Компиляция всех Java-классов через javac (JDK 21) — успешно.
- Отдельная сборка Maven (Apache NetBeans bundled Maven) — BUILD SUCCESS.
- Автономные тесты PracticeSelfTest — 14/14 PASS.
- Визуальная проверка JFrame InfoFrame на Windows и снимок результата.
- Импорт исходников в Eclipse и NetBeans, проверка редактора кода.
- Создание учебной PracticeForm.java/.form штатным Swing GUI Builder NetBeans.

## Измеренные показатели проекта
- Язык и SDK: Java 21.
- Тип: настольный учебный прототип, не веб-приложение.
- 6 основных классов + отдельный JFrame-класс, созданный GUI Builder.
- 14 автоматических проверок, 0 неуспешных.
- 4 поддерживаемые операции калькулятора.
- 38 анимированных снежинок.
- Период таймера: 33 мс (заданное значение, фактический FPS не измерялся).

## Результаты ревью
1. Calculator: явная блокировка деления на ноль; исключение для нечисловых/бесконечных значений; проверка неизвестной операции.
2. ConsoleExamples: валидация диапазона возраста 0..125.
3. Swing: обновление кадров таймером, а не бесконечным циклом repaint() из paintComponent().
4. Graphics2D освобождается через dispose(); Swing Timer останавливается при закрытии окна.
5. UI, вычисления и тесты разделены по пакетам; код читается и собирается с Java 21.

## Ограничения и незавершённые операции
- Зимняя информационная панель является прототипом на Swing, а не официальным продуктом университета.
- Логотип в прототипе — самостоятельно созданная геометрическая эмблема, не официальный товарный знак.
- Форму PracticeForm создали в GUI Builder, но элементы этой конкретной формы ещё не добавлены в дизайнер.
- Настройки Formatter / Refactor Rename / Refactor Move / Archive Export / Delete & ZIP Import в Eclipse не все выполнены через интерфейс.
- Есть локальный git, но пока нет удалённой публикации на GitHub.
- Даты, часы, официальные подписи и согласование не установлены.
