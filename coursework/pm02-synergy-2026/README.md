# ПМ.02: ревьюирование программных модулей

Учебный Java 21 / Swing проект для производственной практики. Исходники, тесты, демонстрация анимации и NetBeans GUI Builder.

Репозиторий используется только как место размещения учебного проекта внутри отдельной папки `coursework/pm02-synergy-2026`. Персональные отчётные документы и подписи не публикуются.

Сборка Windows: `build_windows.bat`.

Тесты Windows: `run_windows.bat test`.

Демонстрация Windows: `run_windows.bat`.
